# Telegram Admin Bot

Личный Telegram-бот с правами администратора для управления группой.
Автоматизирует модерацию, ведёт учёт участников и оптимизирует
процессы в чате.

>  **Важно:** бот написан под конкретную группу и её задачи.
> Универсального применения не предполагает.

## О проекте

Бот выполняет административные функции в Telegram-группе: следит за
порядком, обрабатывает команды пользователей, ведёт статистику и
автоматизирует повторяющиеся действия модераторов.

## 🛠️ Стек технологий

- **Язык:** Python 3.11+
- **Библиотека:** aiogram 3.0.0b7
- **Хостинг:** локально
